# F1 Live Schedule

## プロジェクト概要

2026年のF1セッションを日本時間で確認できる、HTML・CSS・JavaScript製のスケジュールアプリです。グランプリのカードを開くと、フリー走行、予選、決勝の開始日時を確認できます。

## 解決する問題

海外開催のF1は深夜0時をまたぐセッションがあり、日付と時刻を別々に管理すると更新時に食い違う可能性があります。このアプリでは、確認済みの日本時間をタイムゾーン付きの1つの文字列として保存し、表示と状態判定の両方に使います。

## 対象ユーザー

ベルギーGPとハンガリーGPの開始時刻を日本時間で確認したいF1視聴者を想定しています。実際の利用者調査はまだ行っていません。

## 主な機能

- ベルギーGPとハンガリーGPのセッション一覧
- すべての開始時刻を日本時間（JST）で表示
- 現在時刻を基準に、表示対象となるセッションを1件選択
- 開催予定時間内、次のセッション、全日程終了の3状態を判定
- 次のセッションまでの残り日数・時・分・秒を表示
- 開催期間、「日程を見る」、矢印によって操作できるカードだと明示
- クリックと、button標準のEnterキー・スペースキーによるカードの開閉
- PC幅とスマートフォン幅に対応した表示

## 日程データ

各セッションは、次の5項目で統一しています。

```js
{
  id: "2026-belgium-qualifying",
  grandPrix: "ベルギーGP",
  sessionName: "予選",
  startAt: "2026-07-18T23:00:00+09:00",
  endAt: "2026-07-19T00:00:00+09:00",
}
```

`+09:00`は日本時間がUTCより9時間進んでいることを表します。現地時間やUTCから実行時に変換するのではなく、確認済みの日本時間を直接保存しています。

## 日程の確認元

2026年7月14日に、以下の情報を確認しました。開始時刻は日本時間で公開されている情報、終了時刻はF1公式タイムテーブルの予定枠を使用しています。

- [FOD INFO：F1 2026シーズンスケジュール](https://news.fod.fujitv.co.jp/motor/f1schedule/)
- [Formula1-Data：2026年F1開催日程](https://formula1-data.com/race/gp)
- [F1公式：2026年ベルギーGPタイムテーブル](https://www.formula1.com/en/latest/article/formula-1-moet-and-chandon-belgian-grand-prix-2026.6TSnaKuwMr6OvrtF0gZbXF)
- [F1公式：2026年ハンガリーGPタイムテーブル](https://www.formula1.com/en/latest/article/formula-1-aws-hungarian-grand-prix-2026.6rqroq0TO24FJxxSOxwXVq.6rqroq0TO24FJxxSOxwXVq)

日程は変更される可能性があります。セッションの状態は実際の中継や走行状況ではなく、保存した予定開始・終了時刻だけを基準にします。

## 使用技術と選定理由

- HTML：画面の基本構造
- CSS：カード表示とレスポンシブ対応
- JavaScript：日時の比較、表示生成、カード操作
- JavaScript標準の`Date`と`Intl`：外部ライブラリなしで日本時間の比較と表示を行うため

対象が日本時間だけであり、現在の規模では標準機能で十分なため、日付処理ライブラリは追加していません。

## セットアップとデモ

1. このフォルダをダウンロードする。
2. `index.html`をブラウザで開く。
3. グランプリのカードをクリックして日程を確認する。

ビルドやパッケージのインストールは不要です。ローカルデモは`index.html`を直接開いて確認できます。

## 操作方法

- マウス：グランプリのカードをクリックする。
- キーボード：Tabキーでカードへ移動し、Enterキーまたはスペースキーを押す。

## 設計上の工夫

- 比較用と表示用の日時を重複して持たず、`startAt`を両方に利用しています。
- 国旗とサーキットは画面用データ、各セッションは日程データに分けています。
- `startAt`と`endAt`の両方を完全な日時にしたため、日付をまたぐ予選や決勝も同じ比較式で判定できます。
- 全セッションを順番に確認し、開催予定時間内のセッションを最優先で1件選びます。
- 開催予定時間内のセッションがなければ、開始時刻が最も近い未来のセッションを選びます。
- 表示対象の判定を1秒ごとに更新し、ページを開いたまま予定開始・終了時刻をまたいでも状態を切り替えます。
- 選択した1件をカード一覧の上へ表示し、開始前は残り時間、開催予定時間内は予定時刻基準のLIVEを示します。
- カード見出しには`button`を使い、独自のキーボード処理を追加せず、ブラウザ標準のEnterキー・スペースキー操作を利用しています。

## 苦労した点

以前はグランプリごとに現在または次のセッションを探していたため、画面全体では複数の候補が選ばれていました。全セッションから1件だけを選ぶため、開催予定時間内のセッションを先に確認し、同時に最も近い未来の開始時刻を記録する処理へ変更しました。

## 今後の改善案

- 他のグランプリを同じ5項目の形式で追加する
- 日程変更を確認しやすい更新手順を作る
- 日時データの自動テストを専用ファイルとして追加する
- 実際の利用者に表示の分かりやすさを確認してもらう
