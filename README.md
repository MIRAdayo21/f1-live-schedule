# F1 Live Schedule

2026年F1の登録済みセッションを日本時間で確認できるWebアプリです

F1を見るときに、次のセッションがいつ始まるのかを毎回調べるのが手間だったため、
次に始まるセッションと開始までの残り時間をすぐ確認できるように作りました

## Demo

https://miradayo21.github.io/f1-live-schedule/

## 主な機能

- 登録したグランプリの日程を日本時間で表示
- 現在または次に始まるセッションを画面上部に表示
- 開始までの日・時・分・秒をカウントダウン
- 開催予定時間内、次のセッション、全日程終了の3状態を判定
- 開催予定時間内のセッションをLIVE表示
- グランプリごとにセッション一覧を開閉
- スマートフォン表示に対応

## 使用技術

- HTML
- CSS
- JavaScript

フレームワークや日付処理ライブラリは使用せず、
JavaScript標準の `Date` と `Intl` を使っています

## 日時データ

セッションの日程は以下の形式で管理しています

```js
{
  id: "2026-azerbaijan-qualifying",
  grandPrix: "アゼルバイジャンGP",
  sessionName: "予選",
  startAt: "2026-09-25T21:00:00+09:00",
  endAt: "2026-09-25T22:00:00+09:00",
}
```

## セットアップ

1. このリポジトリをダウンロードする
2. `index.html`をブラウザで開く
3. グランプリのカードをクリックして日程を確認する

ビルドやパッケージのインストールは不要です

## 設計上の工夫

- 比較用と表示用の日時を重複して持たず、`startAt`を両方に利用
- 国旗・サーキット情報とセッション日程を別データとして管理
- `startAt`と`endAt`を完全な日時として持ち、日付をまたぐ場合も同じ比較式で判定
- 全セッションから開催予定時間内のものを優先して1件選択
- 開催中のものがなければ、開始時刻が最も近い未来のセッションを選択
- 判定を1秒ごとに更新し、ページを開いたままでも状態を切り替え
- カード見出しに`button`を使用し、キーボード操作にも対応

## 苦労した点

初期の状態では、登録したセッションをすべて同じ大きさで表示していたため、次に始まるセッションを一覧から探す必要がありました

そこで、登録されているセッションを現在時刻と比較し、
開催中のセッションがあればそれを優先し、
なければ未来のセッションの中から開始時刻が最も近いものを1件選ぶ処理を追加しました
そして、現在または次に始まるセッションを画面上部に大きく表示し、
開始前はカウントダウン、開催予定時間になるとLIVE表示へ自動で切り替えられるようになりました
